# 본푸드 메뉴 자동관리 웹페이지

1. js/config.js를 열어 Supabase Project URL과 Publishable key를 입력합니다.
2. Supabase SQL Editor에서 제공된 RLS 정책 SQL을 실행합니다.
3. Supabase Authentication > Users에서 관리자 계정을 만듭니다.
4. admin.html에서 로그인 후 .xlsx를 업로드합니다.
5. index.html에서 메뉴가 자동으로 표시됩니다.

주의: service_role/secret key는 config.js에 넣지 마세요.
